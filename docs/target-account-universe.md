# Target Account Universe

## Purpose

This document defines the target account universe for the Urban Mining feedstock acquisition raise.

It supports:

1. feedstock acquisition
2. investor outreach
3. strategic partner development
4. grant and R&D collaboration
5. RIOS relationship intelligence workflows

This is the master sourcing framework for Apollo, LinkedIn Sales Navigator, Clay, RIOS, and manual relationship mapping.

---

# 1. Feedstock Target Universe

## Segment A - Data Centers and Cloud Infrastructure

### Target Profile

Organizations that own, operate, service, or decommission server infrastructure.

### Why They Matter

Data centers generate high-value retired server and PCB-rich hardware through refresh cycles, AI infrastructure upgrades, cooling retrofits, networking upgrades, and end-of-life equipment management.

### Search Criteria

- data center operator
- colocation provider
- cloud infrastructure provider
- AI infrastructure company
- server refresh
- hardware lifecycle
- decommissioning
- IT asset disposal
- sustainability / ESG reporting

### Target Roles

- VP Data Center Operations
- Director of Infrastructure
- IT Asset Manager
- Sustainability Director
- Facilities Director
- Procurement Manager
- Hardware Lifecycle Manager

### Priority Signals

- new data center expansion
- hardware refresh cycle
- sustainability report mentions e-waste
- decommissioning activity
- server lifecycle management
- public commitment to circular economy

### Initial Target Count

Top 100 accounts

# 4. Target Account Data Fields

Each account should be captured with the following fields:

| Field | Description |
|---|---|
| Account Name | Company or organization name |
| Segment | Data center, ITAD, investor, grant partner, etc. |
| Website | Company website |
| Geography | Country, state/province, city |
| Primary Signal | Why this account matters |
| Feedstock Fit Score | 0-100 where applicable |
| Investor Fit Score | 0-100 where applicable |
| Grant Partner Fit Score | 0-100 where applicable |
| Decision Maker | Primary contact |
| Role | Contact title |
| LinkedIn URL | Contact or company profile |
| Email Source | Apollo, direct, manual, referral |
| Relationship Path | Mutual connections or warm intro |
| Outreach Status | Not contacted, contacted, engaged, etc. |
| Next Action | Research, contact, call, LOI, data room, etc. |

Add:

- signals
- geography

- relationship paths

## Step 3 - Score Accounts

Apply:

- feedstock fit score
- investor fit score
- grant partner fit score

## Step 4 - Prioritize

Tier accounts:

- Tier 1: 80+
- Tier 2: 60-79
- Tier 3: 40-59
- Low Priority: below 40

## Step 5 - Route

Route to:

- feedstock supplier campaign

# 7. Strategic Priority

The first account universe should prioritize feedstock before investors.

Reason:

Feedstock LOIs create investor confidence.

The ideal first 90 days should produce:

- supplier discovery calls
- feedstock LOIs
- pilot facility relationships
- investor conversations supported by real supply-side momentum

This target universe should be reviewed and refined every 90 days as part of the 180-day GTM plan.
