# Feedstock Acquisition Strategy

## Mission

Secure recurring high-value PCB and server feedstock that can be converted into precious metal recovery revenue.

## Feedstock Philosophy

Feedstock is the urban mining equivalent of reserves.

Every signed supply agreement increases enterprise value.

## Priority Sources

### Tier 1

Data Centers

Targets:
- hyperscalers
- colocation operators
- AI infrastructure operators
- enterprise server farms

Material:
- servers
- motherboards
- CPUs
- RAM
- storage systems
- networking equipment

### Tier 2

IT Asset Disposition (ITAD)

Targets:
- enterprise IT recyclers
- hardware disposition firms
- secure destruction firms

Material:
- PCB streams
- retired servers
- enterprise electronics

### Tier 3

Telecom

Targets:
- carriers
- network refresh contractors
- telecom infrastructure firms

Material:
- routers
- switches
- telecom PCB assemblies

### Tier 4

Institutions

Targets:
- universities
- hospitals
- municipalities
- government agencies

Material:
- computer refresh inventories
- server room equipment
- networking infrastructure

## Acquisition Process

1. Identify account
2. Research decision maker
3. Map relationship path
4. Conduct discovery call
5. Review inventory profile
6. Request sample information
7. Build pricing framework
8. Draft LOI
9. Execute supply agreement
10. Schedule first shipment

## Success Metrics

- Number of supplier conversations
- Number of LOIs
- Estimated tonnes secured
- Estimated PCB volume secured
- Annualized feedstock value
- Number of recurring suppliers

## Strategic Goal

Create a diversified feedstock portfolio that reduces dependency on any single supplier while increasing predictability of throughput and revenue.
