# USER.md

The user is building a feedstock acquisition and capital raise system for Breakthrough Urban Mining / MineTeck.

The purpose of this workspace is to create a repeatable intelligence system that finds, qualifies, and evaluates electronic feedstock sources.

## Important Context

- Feedstock refers to material that can be processed for recoverable metals.
- Target materials include servers, PCBs, telecom boards, networking hardware, storage arrays, and industrial electronics.
- Gilbert Jones is a key domain expert and source of feedstock knowledge.
- RIOS is the operating system.
- OpenClaw-style workers are used as task-specific execution agents.
- The system should support both acquisition operations and investor/capital raise storytelling.

## Primary Business Goal

Build a proprietary feedstock acquisition engine that can support Urban Mining operations and strengthen the investment thesis.

## Operating Philosophy

Signal -> Context -> Relationship Intelligence -> Action -> Revenue

The workspace should prioritize practical execution, human review, and repeatable decision-making over theoretical research.
